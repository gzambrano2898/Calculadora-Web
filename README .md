# CALCULADORA WEB

## 1. Descripción del proyecto

Este proyecto consiste en el desarrollo de una calculadora web funcional, elaborada mediante HTML5, CSS3 y JavaScript, como parte de la Actividad 3 de la Unidad 1 de la asignatura Desarrollo Web.

La aplicación permite realizar operaciones matemáticas básicas mediante una interfaz gráfica sencilla e interactiva.

## 2. Objetivo

Aplicar los conocimientos de desarrollo web del lado del cliente mediante la creación de una aplicación que integre estructura HTML, diseño CSS y programación JavaScript.

## 3. Tecnologías utilizadas

- **HTML5:** creación de la estructura y los elementos de la calculadora.
- **CSS3:** diseño, colores, distribución y estilos visuales.
- **JavaScript:** implementación de la lógica y operaciones matemáticas.

## 4. Funcionalidades

- Ingreso de números mediante botones.
- Operaciones de suma.
- Operaciones de resta.
- Operaciones de multiplicación.
- Operaciones de división.
- Visualización de los valores y resultados.
- Función para borrar la operación.

## 5. Estructura del proyecto

- `index.html`: contiene la estructura principal de la calculadora.
- `styles.css`: contiene los estilos y el diseño visual.
- `script.js`: contiene la lógica y las funciones de la calculadora.

## 6. Ejecución del proyecto

1. Descargar o clonar el repositorio de GitHub.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar el archivo `index.html` utilizando un navegador web.
4. Interactuar con los botones para realizar operaciones matemáticas.
